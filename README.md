Part 1 — Registration and Login Feature This project is a Java application that demonstrates the basics of object‑oriented programming through a registration and login system. The program allows a user to create an account by entering a username, password, and South African cell phone number. Each input is validated against strict rules: the username must contain an underscore and be no more than five characters long, the password must meet complexity requirements, and the cell phone number must include the international code and be no longer than ten digits. If the inputs are valid, the system confirms successful registration; otherwise, it provides clear error messages. Once registered, the user can log in with their details, and the program returns either a personalized welcome message or an error message if the login fails. This part of the project highlights input validation, conditional logic, and authentication fundamentals, forming the foundation for more advanced features in later parts.
